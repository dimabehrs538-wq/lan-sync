## TeamSync 0.4.1：新增 macOS（Apple Silicon / Intel）

### 新增
- **macOS 桌面版**：Apple 芯片（`aarch64`）与 Intel（`x64`）各一个 DMG。界面、Go 内核、同步协议与 Windows 版相同，内置同版本 Syncthing v2.1.6，可与 Windows / Android / iOS 成员直接互通；数据模型和删除语义不变。
- macOS 适配：菜单栏模板图标（随浅色 / 深色自动变色）；关闭窗口后继续在菜单栏同步，点击程序坞图标重新打开窗口；⌘Q / 菜单栏“退出”先停止同步引擎再退出；开机自启（LaunchAgent）；“在访达中显示”；删除时移到废纸篓（macOS 15 起使用系统 `trash` 命令，无法访问时回到原有确认流程）；内核被强杀后残留的 Syncthing 会在下次启动时自动结束。
- macOS 自动更新：与 Windows 使用同一个 `latest.json` 和同一把 TeamSync 更新签名公钥，下载签名的 `.app.tar.gz` 校验后替换。

### ⚠️ macOS 首次打开（未公证，请先阅读）
- 本项目**没有 Apple 开发者证书**：应用只做了 **ad-hoc 代码签名，未经 Apple 公证**。首次打开会提示“无法验证开发者”或“已损坏”。
  1. 打开 DMG，把 TeamSync 拖到“应用程序”，并从“应用程序”运行（自动更新需要）；
  2. 右键（或 Control 点按）TeamSync → 打开 → 打开；macOS 15 起：先双击一次，再到 **系统设置 → 隐私与安全性** 底部点 **“仍要打开”**；
  3. 仍提示“已损坏”：终端执行 `xattr -dr com.apple.quarantine /Applications/TeamSync.app`。
- **最低系统：macOS 12 Monterey**。
- 首次运行请允许 **“本地网络”** 权限（以及防火墙对 `syncthing` 的传入连接），否则无法发现和连接同事；团队文件夹放在文稿 / 桌面 / 下载 / 外置磁盘时也需允许访问。ad-hoc 签名的应用更新后系统可能再次询问这些权限。
- macOS 版的 Syncthing 由官方源码包（按官方签名的 sha256 清单校验）编译：官方 Intel 二进制要求 macOS 26，无法在 macOS 12–15 上运行。

### 其他平台
- **Windows**：安装包、签名和自动更新方式不变，0.3.x / 0.4.0 可自动更新到本版本（更新公钥未变）。
- **Android**：仍用项目原发布证书签名（证书未变，可覆盖安装）。**iOS**：仍为未签名 IPA。
- 修复：macOS / Unix 上废纸篓目录不可访问时可能无限重试的问题。

|---|---|

| `TeamSync_0.4.1_x64.dmg` | macOS，Intel 芯片，macOS 12+，ad-hoc 签名、未公证 |
| `TeamSync_0.4.1_aarch64.app.tar.gz` / `_x64.app.tar.gz`（+ `.sig`） | macOS 自动更新包（由应用自动下载，无需手动安装） |

| `TeamSync_0.4.1_android_arm64.apk` / `.aab` | Android |
| `TeamSync_0.4.1_ios_arm64_unsigned.ipa` | iOS，**未签名**，需自行重签，iOS 14+ |
| `latest.json` | 自动更新清单（Windows + macOS 两种架构） |
| `SHA256SUMS.txt` | 全部文件的 SHA-256 |

### 测试（实际覆盖范围）
- Go 单元测试（Linux 与 macOS runner）、前端构建、Windows / Android / iOS 构建；Linux 上两节点 / 三节点同步端到端测试；桌面 ↔ 移动端内核互通测试。
- GitHub Actions macOS runner（两种架构各一次构建）：校验主程序、`teamsyncd`、`syncthing` 的 Mach-O 架构与最低系统版本、Info.plist（版本、本地网络等权限说明）、`codesign --verify --deep --strict`（ad-hoc）、内置资源、DMG 内容和更新包结构与签名；冒烟测试：启动 .app 内的内核与 Syncthing、强杀后残留进程回收、启动主程序并退出后进程全部清理（Intel 包在 Apple Silicon runner 上经 Rosetta 2 运行）；macOS 上的三节点同步端到端测试（Apple Silicon；runner 上局域网广播发现不可用，测试中按地址添加成员，因此**局域网自动发现未在 macOS 上验证**）。
- 发布后重新下载全部文件，校验 SHA-256、架构、版本、更新签名（使用原有公钥）与下载链接。
- **尚未在真实 Mac 上做界面验收**，也未在真机上测试从 0.4.1 升级到后续版本；runner 上的检查不等同于真机体验。

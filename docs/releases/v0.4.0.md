## TeamSync 0.4.0：新增 Android 与 iOS

### 新增
- **Android（arm64）**与 **iOS（未签名 IPA）**客户端：与桌面相同的界面和功能，内嵌同版本 Syncthing v2.1.6，可与 0.3.x 桌面端直接互通。
- 成员页支持**按 IP 地址手动添加**（无法局域网发现时使用，例如 iPhone）；"配对"弹窗显示本机局域网地址。
- 手机上可浏览团队文件夹、导入文件、分享/打开文件；冲突中心、删除保护与历史版本恢复全部可用。
- Android：可选"后台同步"（前台服务）、可选授予"所有文件访问权限"把文件夹放到共享存储。

### 桌面端
- 功能与签名、自动更新方式不变（Windows 安装包与 latest.json 照常发布，0.3.x 可自动更新到本版本）。
- 修复一个日期写死导致单元测试过期失败的问题；内核启动流程抽成公共模块，桌面行为不变。

### 移动端限制（请先阅读）
- **Android**：前台时同步；开启"后台同步"后以通知栏常驻服务运行，但系统可能因省电结束它，Android 15 起每天最多约 6 小时。
- **iOS**：只在 App 处于前台时同步，切到后台会被系统挂起；没有局域网自动发现，需要手动输入对方地址；首次需要允许"本地网络"权限。
- 手机没有回收站："删除本地文件"为永久删除（界面会明确提示）。

### 安装
| 文件 | 说明 |
|---|---|
| `TeamSync_0.4.0_x64-setup.exe` / `.msi` | Windows 安装包（与以往相同） |
| `TeamSync_0.4.0_android_arm64.apk` | Android 安装包，已用项目发布证书签名，可直接安装（需允许安装未知来源应用） |
| `TeamSync_0.4.0_android_arm64.aab` | Android App Bundle（上架商店用） |
| `TeamSync_0.4.0_ios_arm64_unsigned.ipa` | **未签名**，不能直接安装、未上架 App Store；需用 AltStore/SideStore/Sideloadly 或自己的开发者证书重签，iOS 14+ |
| `SHA256SUMS.txt` | 全部文件的 SHA-256 |

### 测试
- Go 单元测试（桌面内核 + 移动端内核）、前端构建。
- e2e：桌面 ↔ 移动端内核互通（手动地址配对、导入/导出、5 MB 文件、冲突、删除保护恢复、只读、重启、永久删除），以及三节点 e2e 中分别把 A / B、C 换成移动端内核。全部使用本机回环与临时数据。
